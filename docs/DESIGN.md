# Design notes

**Objective:** escape the house -> reach the basement altar.

**Critical path:** Garden (Brass Key) -> Grand Hall (door seals behind you, Watcher awakens) -> Office (brass key) -> Library diary (code 417) -> Office safe (Iron Key) -> Basement door -> altar.

**Optional branch (more crystals, lore):**
Office -> Kitchen (Bedroom Key, note) -> Guest Bedrooms via the Library north door (diary: code 209, brass gear, Shadows appear) -> Kitchen stove dials 209 opens the cabinet (second gear) -> Bedrooms lever opens the hidden door -> Secret Laboratory -> machine with 2 gears opens the vault (2 crystals + note).
Library symbol panel (Moon, Eye, Fox) opens the secret nook (crystal, med kit, ammo).

11 crystals exist; 5 or more = good ending; all 11 = extra line in the good ending.

**Map (x east, z south):** Garden z16..40 | Hall x +-9, z0..16 | Corridor x9..25, z6.5..9.5 | Library x25..41, z0..16 | Office x-25..-9, z0..16 | Basement x +-9, z-18..0 | Kitchen x-25..-9, z-18..0 | Guest Bedrooms x25..41, z-18..0 | Laboratory x9..25, z-18..0.
