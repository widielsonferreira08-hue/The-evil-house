# Design notes — Chapter 1

**Objective:** escape the house → reach the basement altar.

**Critical path:** Garden (Brass Key) → Grand Hall (door seals behind you, Watcher awakens) → Office (brass key) → Library diary (code 417) → Office safe (Iron Key) → Basement door → altar.

**Optional:** Library symbol panel (Moon → Eye → Fox) opens the secret nook (crystal, med kit, ammo). 7 crystals exist; 5 or more = good ending.

**Map (x east, z south):** Garden z16..40 · Hall x±9, z0..16 · Corridor x9..25, z6.5..9.5 · Library x25..41, z0..16 · Office x-25..-9, z0..16 · Basement x±9, z-18..0.
